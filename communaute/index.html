Siflo sur Siflo

Le groupe de la communauté, dans l’application : vos retours, vos idées, les bugs que vous trouvez. Les membres voient les pseudos les uns des autres, rien d’autre.

Rejoindre le groupe dans Siflo

Siflo n’est pas encore installée ?

  1. Copiez le lien du groupe et installez Siflo, gratuite et sans compte.
  2. Ouvrez Siflo et touchez « Coller » : le groupe s’ajoute.

    Si Siflo ne vous le propose pas, revenez sur cette page et touchez « Rejoindre le groupe dans Siflo ».

Scannez ce code avec l’appareil photo de votre téléphone, Siflo installée : le groupe s’ouvre dans l’application. Pas encore installée ? Téléchargez Siflo.

Vous parlez anglais ? Le groupe anglophone est sur siflo.app/community. Découvrir Siflo
